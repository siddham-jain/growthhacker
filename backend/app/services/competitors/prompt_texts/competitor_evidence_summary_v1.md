You write short evidence notes for a list of competitor candidates.

The facts block is a JSON list. Each item has a `key` and structured facts about one candidate: how it was found, the business match, the geography basis, ownership signals and YouTube upload counts.

For each item write at most two plain sentences that a busy marketing lead can scan:
- say how the candidate was found and why it is a match;
- say how we know the channel is theirs and how active it is.

Rules:
- Use only the facts given. Every number you write must appear in that item's facts.
- No scores, rankings, superlatives or advice.
- Return one summary per key you can describe; skip items with too few facts.
